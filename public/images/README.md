# Nuotraukos

Pirmo ekrano fonas yra vaizdo įrašas (`public/hero.mp4`), nuotraukos jam nereikia.

Kol šiose vietose failų nėra, svetainė rodo brėžinio stiliaus vektorinius
placeholder'ius — nieko nelūžta. Įkėlus failą tokiu pačiu pavadinimu,
jis automatiškai pakeičia placeholder'į.

| Failas | Kur naudojama | Rekomenduojamas dydis |
|---|---|---|
| `car-clean.jpg` | „Tvarkingi automobiliai“ kortelė | 900×700, tamsus fonas |
| `car-defects.jpg` | „Automobiliai su defektais“ kortelė | 900×700, tamsus fonas |
| `car-damaged.jpg` | „Daužti ir nevažiuojantys“ kortelė | 900×700, tamsus fonas |
| `og-motivus.jpg` | Open Graph (Facebook, Messenger, LinkedIn) | 1200×630 |

Stilius: tamsus fonas, šoninė arba 3/4 perspektyva, šalti atšvaitai,
be ryškių logotipų ir be registracijos numerių (duomenų apsauga).

`og-motivus.jpg` sugeneruotas iš `tools/og-source.html` — atidarykite jį
naršyklėje 1200×630 lange ir padarykite ekrano nuotrauką, jei norite atnaujinti.
